# 热点晨报 · 前端设计规格（可直接指导开发）

> 版本 v2.0 · 2026-11-06
> 本文是开发依据：信息架构、页面职责、交互闭环、状态与异常、响应式、视觉约束、验收标准。
> 配套部署方案见 `docs/deploy-cloudflare.md`。

---

## 一、设计上下文（先定人，再定界面）

| 项 | 定义 |
|---|---|
| **主用户** | 中文信息重度读者 / 职场人。每天早上 3–5 分钟扫完「昨夜今晨发生了什么」，通勤或到工位后打开。 |
| **次用户** | 内容运营、自媒体、投研。要盯几个关键词，追某话题的排名变化，顺手拿走可引用的标题与链接。 |
| **边缘用户** | 开发者 / AI 用户。把站点当数据接口用（REST / MCP），偶尔查数据源健康度。 |
| **核心场景** | ① 晨间速览（读日报 → 扫热榜 → 点开 2–3 条）② 关键词盯梢（输入「AI 芯片」，看命中）③ 复盘走势（某话题过去 4 小时排名曲线）④ 取素材（复制标题/链接、导出当日简报）⑤ 排障（某源空了，看是上游挂了还是网络问题） |
| **反场景** | 不做社交（无评论/点赞/关注）、不做个性化推荐算法、不做登录墙。 |
| **品牌调性** | **晚报编辑部 + 数据台**：纸感、克制、精确、有编号和细线，像一份每天更新的号外；不是科技蓝仪表盘，不是资讯流 App。 |
| **一句话差异点** | 「一份能被检索、能看走势、能核对来源的晨报」——大多数热点站只有列表，本站每条内容都可追溯来源与时间。 |

## 二、整体信息架构（IA）

```
热点晨报
├── 晨报 /#/today            ← 默认首页
│   ├── 今日（60 秒日报 15 条 + 封面 + 农历/星期 + 原文链接）
│   ├── 往期（按日期归档，最多 30 天）
│   └── 今日速览（可折叠：各分类 Top3、新上榜、数据角标）
├── 热榜 /#/boards
│   ├── 分类：全部 / 国内 / 国际 / 科技 / 财经 / 社会
│   ├── 状态：全部 / 已接入 / 不可用
│   ├── 关键词表达式筛选（+必含 !排除 /正则/ @限量）
│   └── 视图切换：卡片 / 紧凑列表
├── 走势 /#/trends
│   ├── 选源 → 选话题 → 排名曲线（真实快照）
│   ├── 涨跌榜（今日新上榜 / 上升最快）
│   └── 采集批次时间线
├── 数据 /#/data
│   ├── 实用数据：金价 / 油价 / 汇率 / 天气 / 历史上的今天 / Epic 免费游戏
│   └── 影视榜：猫眼 4 榜 / 豆瓣 5 榜 / 百度电视剧
├── 数据源 /#/sources
│   ├── 健康总览（可用/不可用/延迟）
│   ├── 源明细表（通道、条目数、最近成功时间）
│   └── 单源重试 + 全部重试
└── 更多 /#/more
    ├── 关于与数据来源（60s / NewsNow / 许可）
    ├── API 说明（/api/v1/*，含示例）
    ├── 内容后台（本地录入未接入源，标注「人工录入」）
    └── 偏好（主题：跟随系统 / 纸 / 夜；密度：舒适 / 紧凑）
```

**导航关系**
- 桌面（≥1024px）：左侧固定侧栏（品牌 + 一级导航 + 采集状态 + 日期），主区单视图，右侧可选的「本批次速览」栏（仅晨报页）。
- 平板（640–1023px）：侧栏收起为顶部横向 tab，主区单列。
- 移动（<640px）：底部固定 5 个 tab（晨报/热榜/走势/数据/更多），顶栏保留检索与刷新；「数据源」收进「更多」。
- 所有切换走 hash 路由，可前进/后退/分享链接；切换不整页刷新，保留滚动位置。

## 三、页面清单与职责

| # | 页面 | 路由 | 职责 | 主要模块 | 数据来源 |
|---|---|---|---|---|---|
| 1 | 今日晨报 | `#/today` | 3 分钟读完当天要闻 | 日报正文、封面、农历/星期、原文链接、往期切换、分类速览 | `/api/v1/digest` |
| 2 | 往期归档 | `#/today?date=` | 回看历史晨报 | 日期选择器、归档列表、缺省说明 | `/api/v1/digest?date=` |
| 3 | 分类热榜 | `#/boards` | 一屏扫完各平台热榜 | 分类 tab、状态 tab、关键词输入、卡片/列表、趋势徽标 | `/api/v1/boards` |
| 4 | 走势 | `#/trends` | 判断「在发酵还是在退烧」 | 源选择、话题列表、SVG 曲线、涨跌榜、批次时间线 | `/api/v1/trends`、`/api/v1/topics` |
| 5 | 实用数据 | `#/data` | 与热点相关的日常数据 | 金价/油价/汇率卡、天气卡、历史上的今天、Epic | `/api/v1/metrics`、`/api/v1/misc` |
| 6 | 影视榜 | `#/data?tab=media` | 票房与口碑 | 猫眼 4 榜、豆瓣 5 榜、百度电视剧 | `/api/v1/media` |
| 7 | 数据源 | `#/sources` | 判断内容缺失的原因 | 健康总览、明细表、重试、通道说明 | `/api/v1/sources`、`/api/v1/health` |
| 8 | 更多 | `#/more` | 说明、接口、本地编辑、偏好 | 关于、API 示例、内容后台、主题/密度 | 静态 + localStorage |
| 9 | 检索结果 | `#/boards?q=` | 跨源找同一条新闻 | 结果计数、按源分组、命中高亮 | 前端本地检索（对已加载榜单） |
| 10 | 404 | 任意未知路由 | 兜底 | 返回晨报、搜索建议 | — |

> **页面数量原则**：一级 5 个（晨报/热榜/走势/数据/更多），数据源作为「更多」下的二级页并在桌面侧栏暴露，避免导航过载。移动端 5 个 tab 与一级导航一一对应。

## 四、关键功能模块

### 4.1 数据展示

| 模块 | 规格 |
|---|---|
| 日报正文 | 有序列表 01–15，衬线正文，行高 1.75；序号用等宽数字；`tip` 用引号块；`cover` 作为页首大图（无图时用纸纹底纹） |
| 热榜卡片 | 源名 + 通道徽标 + 更新时间 + Top10（可展开到 30）；排名 01/02…；热度值右对齐；趋势徽标 `新` / `▲n` / `▼n` / `—` |
| 紧凑列表 | 单行：序号 · 标题 · 源名 · 趋势；≤30 条；适合快速扫 |
| 趋势曲线 | SVG 折线 + 面积；x 轴为采集批次；y 轴为排名（越小越高）；点少（<3）时显示「样本不足」而不是画假线 |
| 数据卡 | 大字数值 + 单位 + 涨跌 + 更新时间；无数据时显示「—」和原因 |
| 影视榜 | 三组 tab，每组榜单一列；显示排名、标题、评分、上榜时间 |
| 空状态 | 说明「为什么空」+ 下一步动作（重试 / 换源 / 查看数据源） |

### 4.2 表单与交互

| 交互 | 行为 |
|---|---|
| 关键词输入 | 300ms 防抖；支持 `+必含`、`!排除`、`/正则/`、`@N`；非法正则即时提示且不崩；右侧显示「命中 N 条」 |
| 分类/状态 tab | 单选；URL 同步（`?cat=&status=`），可分享 |
| 源多选 | 热榜页可选「只看某几个源」，选择存 localStorage |
| 日期选择 | 晨报往期：日期输入 + 前/后一天按钮；未来日期禁用 |
| 全局检索 | 顶栏输入，回车跳 `#/boards?q=`；`⌘K` / `Ctrl+K` 聚焦；Esc 清空 |
| 重试 | 单源重试按钮；全部重试；重试中禁用并显示 spinner |
| 内容后台 | 表单：源、标题、链接、备注；校验必填与 URL 格式；保存到 localStorage；列表可删除；导出 JSON |
| 主题/密度 | 即时生效，写 localStorage；`prefers-color-scheme` 为默认 |
| 导出/分享 | 复制当日简报（Markdown）、复制单条标题+链接、复制当前视图链接 |

### 4.3 状态反馈（每页必须有四态）

| 状态 | 表现 |
|---|---|
| **加载** | 骨架屏（形状匹配最终内容），不使用全屏 spinner；>8s 显示「仍在请求…」和取消提示 |
| **成功** | 内容 + 最后更新时间 + 通道徽标 |
| **空** | 说明原因（无数据 / 未接入 / 关键词无命中）+ 主行动按钮 |
| **错误** | 人话说明 + 错误码（小字）+ 重试 + 去「数据源」排查 |
| **降级** | 后端不可达 → 自动切 `demo.json` 快照，顶部横幅注明「静态快照 · 采集于 X」，并隐藏实时功能 |
| **离线** | `navigator.onLine=false` 时横幅提示，恢复后自动重试一次 |
| **全局提示** | Toast（3s 自动消失，可手动关），右侧右下角，移动端底部避开 tab |

### 4.4 权限模型

- 站点**公开只读**，无账号、无登录墙。
- 「内容后台」仅写浏览器 localStorage，不写服务端；所有人工条目固定带「人工录入」标记，且不参与趋势与热词统计。
- 服务端写接口（如未来的推送配置）使用 `Authorization: Bearer <token>`，前端不存储 token；本期不实现写接口。
- 管理能力（重试、清理缓存）仅影响本地缓存，不涉及他人数据。

### 4.5 异常与边界

| 情况 | 处理 |
|---|---|
| 上游超时 | 客户端 10s 超时，指数退避重试 1 次，之后展示错误态 |
| 部分源失败 | 单源失败不影响整页；卡片局部错误 + 重试 |
| 接口返回结构异常 | 校验 `code===200 && Array.isArray(items)`，否则按错误处理，不渲染半截数据 |
| 标题超长 | 2 行截断 + `title` 属性；列表视图 1 行 |
| 无 URL | 渲染为不可点击文本，不生成 `javascript:void(0)` |
| 特殊字符 | 全部走 `textContent` 或转义，禁止拼接未转义 HTML |
| 正则非法 | try/catch，提示「正则不合法」，退回普通包含匹配 |
| 时区/日期 | 统一 `Asia/Shanghai` 展示，接口存 UTC 时间戳 |
| 大量条目 | 热榜默认 10 条、展开 30 条；列表虚拟化暂不做，用 `content-visibility: auto` |

## 五、响应式适配要求

| 断点 | 布局 | 关键调整 |
|---|---|---|
| `< 640px` 移动 | 单列 + 底部 tab（56px + safe-area） | 顶栏只留检索图标与刷新；日报字号 17px；卡片单列；趋势图高度 160px；触控目标 ≥44×44 |
| `640–1023px` 平板 | 单列 + 顶部横向导航 | 热榜两列；数据卡两列；隐藏右侧速览栏 |
| `1024–1439px` 桌面 | 侧栏 232px + 主区 | 热榜三列；数据卡三列；右侧速览栏（仅晨报） |
| `≥1440px` 宽屏 | 侧栏 + 主区（max 1180px）+ 右栏 | 热榜四列；行宽控制在 68–76 字符 |

实现要求：
- 用 **容器查询** 控制卡片内部布局（`@container`），用媒体查询控制页面骨架。
- 字号用 `clamp()`，间距用 `clamp()`；禁止固定 px 造成移动端溢出。
- 横屏与 320px 极窄屏不横向滚动；表格在移动端转为定义列表。
- 图片 `aspect-ratio` + `object-fit: cover`，避免 CLS。
- 打印样式：隐藏导航，单栏，黑白友好（用户会打印晨报）。

## 六、视觉与交互风格约束

### 6.1 设计语言：晚报编辑部

- **底色**：暖纸 `oklch(0.965 0.014 85)`；夜间为墨纸 `oklch(0.19 0.012 70)`。禁止纯白/纯黑。
- **主色**：朱红 `oklch(0.52 0.17 30)`，仅用于：印章、当前导航、关键数字、强调线。占屏面积 <5%。
- **文字**：墨色 `oklch(0.24 0.022 60)`；次级 65% 透明；禁用灰阶纯灰。
- **标题**：Noto Serif SC / Songti SC（衬线，字重 700–900，字距 0.06–0.14em）。
- **正文**：Noto Sans SC / PingFang SC，17px / 1.75。
- **数字**：等宽 `ui-monospace, "SF Mono", Consolas`，用于排名、热度、日期、曲线轴。
- **线条**：1px 细线分栏（`--hairline`），用「双线 + 短粗线」做栏目标题，替代卡片阴影。
- **圆角**：≤6px；按钮 4px；禁止 16px+ 大圆角。
- **阴影**：几乎不用；仅在浮层用 `0 1px 0` 硬边或 1px 描边。
- **纹理**：极轻纸纹（SVG noise，opacity ≤0.03），仅桌面。
- **图标**：内联 SVG，1.5px 线宽，24px 网格。

### 6.2 明确禁止（AI Slop 清单）

- 紫蓝渐变、青紫霓虹、发光边框、玻璃拟态、深色+荧光。
- 卡片套卡片、每个区块都圆角+阴影、居中一切。
- 大图标 + 标题 + 副标题的模板化 hero。
- 无意义的进度环、仪表盘、粒子背景。
- 「赋能/一站式/全新升级」类空话文案。

### 6.3 动效

- 时长 180–320ms；缓动 `cubic-bezier(0.16, 1, 0.3, 1)`（ease-out-quart）。
- 只动 `transform` / `opacity`；列表入场逐条 30ms 递延，最多 8 条。
- 视图切换：淡入 + 上移 8px；不整页翻转动效。
- `prefers-reduced-motion: reduce` 时全部关闭。
- 加载骨架用 1.2s 循环渐变，不闪烁。

### 6.4 文案规范

- 标题用陈述句，不用「震惊/速看」。
- 错误文案：发生了什么 + 为什么 + 怎么办，三句以内。
- 空状态：不写「暂无数据」，写「该源今日尚未返回内容，可能被上游限流」。
- 时间统一「11 月 6 日 07:32」，相对时间仅用于 1 小时内。

## 七、功能完整性验收标准

### 7.1 页面级（每页逐项打勾）

| 验收项 | 标准 |
|---|---|
| 四态齐全 | 加载骨架、成功、空、错误均可复现（可用断网/改 URL 模拟） |
| 交互闭环 | 每个可点元素有结果；每个异步动作有进行中/成功/失败反馈；失败可重试 |
| URL 可分享 | 分类、状态、关键词、日期、选源均反映在 URL，刷新后保持 |
| 键盘可达 | Tab 顺序合理；焦点可见；Esc 关浮层；Enter 触发主操作 |
| 移动可用 | 375×812 下无横向滚动；底部 tab 不遮挡内容；触控 ≥44px |
| 无假数据 | 无「示例热点」；不可用即显示不可用及原因 |
| 可追溯 | 每条内容可看到来源名、通道（60s/newsnow/直连）、更新时间 |

### 7.2 功能级验收清单

- [ ] 晨报：日报 15 条完整显示，序号/正文/引语/封面/农历/原文链接齐全
- [ ] 晨报：可切换前一天的归档；无归档时给出明确说明而非空白
- [ ] 热榜：5 个分类切换正确；「已接入/不可用」过滤正确；计数与列表一致
- [ ] 热榜：关键词 `+必含 !排除` 生效；`/正则/` 生效；非法正则提示不崩
- [ ] 热榜：卡片/列表切换后滚动位置不跳顶；展开 30 条正常
- [ ] 走势：选源后列出话题；点话题出曲线；样本 <3 显示「样本不足」
- [ ] 走势：涨跌榜的条目可点击跳到对应源
- [ ] 数据：金价/油价/汇率/天气/历史今天/Epic 至少 5 项有真实数据；失败项显示原因
- [ ] 影视：三组榜单可切换；空榜显示说明
- [ ] 数据源：49 源状态、通道、条目数、最近成功时间正确；单源重试生效
- [ ] 检索：顶栏输入回车跳转并高亮命中；`⌘K` 聚焦；Esc 清空
- [ ] 更多：主题/密度切换即时生效并持久化；内容后台可增删导出
- [ ] 降级：断开 API 后自动进快照模式，横幅显示采集时间，实时按钮禁用
- [ ] 分享：复制简报/单条/链接均成功并有 toast

### 7.3 质量门槛

| 项 | 门槛 |
|---|---|
| 性能 | 4G 模拟下 LCP < 2.5s；CLS < 0.1；首屏 JS（gzip）< 80KB；无渲染阻塞字体 |
| 可访问性 | 正文对比度 ≥4.5:1；所有交互有可见焦点；图片有 alt；`aria-live` 播报加载/错误；提供跳转主内容链接 |
| 兼容 | Chrome/Edge/Safari 最近两个大版本；iOS Safari 16+；Firefox 最近两个版本 |
| 健壮性 | 任一接口 500/超时不影响其他区块；无未捕获 Promise 异常（控制台干净） |
| 一致性 | 所有间距为 4px 倍数；所有颜色来自 token；无内联魔法值 |

## 八、组件与代码组织（指导落地）

```
public/
├── index.html            # 壳：侧栏/顶栏/视图容器/底部 tab
├── style.css             # token + 组件 + 响应式 + 打印
└── js/
    ├── app.js            # 入口：导航、主题、全局检索、路由注册
    ├── router.js         # hash 路由 + 视图挂载 + 滚动恢复
    ├── api.js            # 请求封装：超时/重试/降级/快照回退
    ├── ui.js             # DOM 助手、格式化、骨架、空/错状态、toast、modal
    └── views/
        ├── today.js      # 晨报（含归档）
```

约束：
- 零构建、零依赖、原生 ES Module；仅用 `fetch` 与 DOM API。
- 每个 view 导出 `{ render(ctx, state), destroy() }`，路由负责卸载，避免监听器泄漏。
- 所有网络请求经 `api.js`，统一错误对象 `{kind:'timeout'|'http'|'parse'|'offline', message}`。
- 不允许在 view 内直接拼未转义 HTML；统一走 `ui.esc()` / `textContent`。
